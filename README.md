# ProcessingRhythmGame
Rhythm Game made in the Processing IDE for AP Computer Science A

Use the number keys 1-8. Press the keys when the note reaches the bottom.

# How to Play:

1. Download these folders and open **music.pde** in the **music** folder within the Processing IDE. 
2. Download Processing's "Sound" library and install it.
3. Press play.

To change your song, change the **filename** variable from one of the following:

- "thrlines" -> Northern Desert (remake) by threelines3 (<https://www.youtube.com/watch?v=RqiNVWJtg8c>)
- "nausicaa" -> Kaze no Tani no Nausicaa by Joe Hisaishi, Piano Ver (<https://www.youtube.com/watch?v=9Nl0UONupYw>)
- "summer" -> Summer by Joe Hisaishi (<https://www.youtube.com/watch?v=l0GN40EL1VU>)
- "liebestraume" -> Liebesträume No. 3 by Liszt (<https://www.youtube.com/watch?v=MBOa-2b4uQQ>)
- "twinkle" -> Twinkle, Twinkle, Little Star (<https://www.youtube.com/watch?v=yCjJyiqpAuU>)

# How to Record:

1. Download the "musicrec" folder and open it on the Processing IDE.
2. Put the .mp3 of your desired song in the "data" folder of the musicrec folder.
3. Change the "filename" variable within musicrec.pde to the title of your .mp4 file.
4. Press play, and press the 1-8 number keys to record your rhythm game.
5. Once the song is finished, press the "a" key to obtain two comma-separated lists of numbers in the console.
6. Create a new file with the same name as the .mp3 file, but with .csv at the end.
7. Within this .csv file, copy the two comma-separated lists and paste them into two distinct lines.
8. Put both the .csv and the .mp3 files into the "data" folder in the "music" project.
9. Put the name of the file (without the attachment) into the "filename" variable in music.pde in order to play.
